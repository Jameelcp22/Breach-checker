


# 🛡️ Breach-Checker

A cybersecurity tool that analyzes password strength using **Entropy Calculation** and checks for compromised credentials using the **Have I Been Pwned API**.

> **Note:** This is an educational project built to explore cybersecurity concepts, Python scripting, and API integration.

##  Features
* **Entropy Score:** Mathematically calculates how hard a password is to guess.
* **Breach Detection:** Safely checks if your password has appeared in known data leaks.
* **Privacy Focused:** Uses k-Anonymity (SHA-1 Hashing) so real passwords are never sent over the internet.

##  Installation

1. **Check for Git:**
   Ensure you have Git installed on your system:
   ```bash
   git --version

2. **Cloning the Repo:**
  Opne your terminal and run the following command
```bash
   git clone https://github.com/Jameelcp22/Breach-checker
```
3. **Downloading the requirements:**
Run the following command on terminal
```bash
  pip install -r requirements.txt
```
4. **Navigate to the Directory:**
```bash
  cd Breach-Checker
```
5. **Run the script:**
  ```bash
  python3 main.py
```
